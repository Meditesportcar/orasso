# Logo

Le logo Orasso validé le 14 octobre 2026 : lettrage « affiche de course » dessiné sur Archivo Expanded Black Italic, le premier O contient la voiture jaune vue de dessus dans son emplacement, chaque lettre passe sur la suivante.

- `orasso-logo-principal-fond-sombre.svg` : sur `ground` Béton, `night`, et toute photo sombre.
- `orasso-logo-principal-fond-clair-800px.png` : sur `ground` Sable, `poster` et fonds clairs. Le SVG équivalent est dans le kit.
- `orasso-monogramme-fond-sombre.svg` : le O crème, en dessous de 100 px de large (barres Béton, centre des QR, icône, pastille).
- `orasso-monogramme-fond-clair.svg` : le O noir, même usage sur les barres Sable et tout fond clair (décision du 15/10).
- `orasso-chargement-fond-sombre.svg` : l'indicateur de chargement, en boucle de 1,6 s, 48 à 120 px.

Règles : marge minimale d'une demi-hauteur de O ; jamais déformé, recoloré, ombré ni contourné ; l'ordre de chevauchement ne change pas. La version sur jaune, les versions monochromes, les favicons, les badges « Propulsé par Orasso » et les vidéos sont dans le kit complet (`C:\Users\DELL\Orasso\identite`, LISEZ-MOI.md).
