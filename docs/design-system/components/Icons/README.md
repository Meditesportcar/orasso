# Icons

Le jeu d'icônes d'Orasso : 32 pictogrammes en trait de 2 px, coins et bouts arrondis, sur une grille de 24 px.

- Toujours en `currentColor` : l'icône prend la couleur du texte qu'elle accompagne (`ink`, `ink-muted`, `accent-ink` sur un bouton moutarde).
- **Un bouton porte toujours une icône** à gauche de son libellé (20 px sur un bouton principal, 18 px sur un secondaire, 22 px sur les grandes tuiles du mode staff). Les boutons qui ouvrent un mode plein écran ajoutent la flèche « suivant » à droite.
- Les titres de carte (`poster-m`) peuvent porter une icône de 16 px : Autour de moi (lieu), Agenda (agenda). Les titres d'affiche (`poster-xl`, `poster-l`) n'en portent jamais.
- Les étiquettes (`label`) portent une icône de 14 px quand elles sont cliquables (Liste, Ajouter, Suivre).
- La barre d'onglets utilise accueil, explorer, qr (Accès), véhicule (Garage), boîte ; l'onglet actif est rempli (`fill: currentColor`), les autres en trait.
- Icônes réservées : alerte (rouge, mode staff et annulation), express (l'éclair, inscription express seulement), grade (l'étoile, points et grades seulement). Pas d'emoji, jamais.
- Le consommateur fournit : le nom de l'icône et sa taille ; la couleur vient du contexte.
- Jeu à compléter à l'étape 7 et au développement : météo (soleil, nuage, pluie), paramètres, sécurité, caméra, galerie, pointage, zone, pro, structure vérifiée.
