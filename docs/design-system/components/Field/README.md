# Field

Champs de formulaire : étiquette étroite au-dessus, champ de 48 px, aide en dessous.

- Étiquette en style `label` (`ink-muted`), champ en `body` sur `surface-raised`, contour `line`, `radius-md`, 48 px (56 px dans l'inscription express sur place).
- Focus : contour `accent-text` et `neon-accent-soft`. Erreur : contour `win-text`, message en `caption` rouge sous le champ, jamais une icône seule.
- Sélection fermée (marque, modèle, génération, catégories) : même forme, avec l'option « Autre » toujours en dernier ; aucune saisie libre pour ces listes.
- Case à cocher : 24 px, `radius-sm`, cochée en `accent`. Les deux cases de la candidature (suivre, newsletter) ont leur phrase complète à côté, pas un libellé d'un mot.
- Mot de passe : saisi deux fois dans l'inscription express, avec l'œil pour afficher.
- Le consommateur fournit : étiquette, valeur, aide, erreur, options.
