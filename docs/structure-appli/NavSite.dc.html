Site web · orasso.fr

Un site public qui référence, un espace connecté qui reflète l'appli, trois espaces de gestion

Le site permet tout. Côté passionné, il reprend les cinq sections de l'appli dans une navigation latérale, pour qu'on ne réapprenne rien. Les espaces organisateur, pro et admin sont des outils de gestion : barre latérale, tableaux, clavier. Tout est aussi utilisable sur téléphone.
